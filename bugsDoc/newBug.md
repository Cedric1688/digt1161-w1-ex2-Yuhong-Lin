# Bug Report: Navigation Menu Overflow on Mobile

## Description
When viewing the website on a mobile device, the navigation menu items overflow outside the screen boundary.

## Steps to Reproduce
1. Open the homepage on a mobile browser or switch to mobile view in DevTools.
2. Click on the navigation menu icon.
3. Observe the right side of the screen.

## Expected Behavior
The navigation menu should fit within the screen bounds and scroll vertically if necessary.

## Actual Behavior
The menu options extend past the right edge of the screen, making some links unclickable.

## Environment
* **OS:** iOS 17 / Android 14
* **Browser:** Safari / Chrome
